# WriteWise · 高考英语写作批改与提升

基于 Next.js + TypeScript 的文本学习闭环，面向应用文与读后续写。详细需求见 [开发规范](docs/PRD.md)。当前完成文档阶段0—2的文本MVP；不代表教学效果已验证或真实学校权限已就绪。

## 运行与检查

Node.js 22.14+，保留现有锁文件：

```sh
npm ci
npm run dev
```

```sh
npm run lint
npm run typecheck
npm test
npm run test:e2e
npm run build
npm start
```

Playwright 使用独立端口3100与强制mock环境，不会复用正在运行的真实模型服务。默认 Chromium 路径 `/usr/bin/chromium`，其他机器通过 `CHROMIUM_PATH` 设置。单元测试使用HTTP桩，不消耗真实模型额度。

## 本轮实现

- WriteWise界面、两题型表单、可编辑任务要点与原文事实提取；用户确认上下文后完整反馈，否则限制评价范围。
- 五维内部能力等级与不同题型权重。上下文不足的维度不可评估，不按0分处理；指数不线性转换考试分数。
- 题目、阅读原文、给定段首句、学生正文分源引用；精确引文、UTF-16索引、重复引文歧义、故事矛盾双源证据验证。
- 英文词数en-v1；续写给定句不计入学生词数，另展示含给定句总词数。
- 按具体问题请求三级提示，局部示例默认关闭；记录学生自述与异议，不推断提示采纳。
- 二稿独立分析及逐条比较，区分已解决、部分改善、尚未解决、无法判断和新问题。片段删除不直接等于已解决。
- 本机教师角色：反馈与比较分别复核，保留AI原文；JSON导出、学生删除、刷新保留。
- 隔离 `wensi-tasks-v1` 与 `writewise-tasks-v2`；旧语文记录只读导出，不转换旧分数、不自动删除。损坏存储不覆盖，跨窗口冲突暂停保存。
- 明确区分Mock与真实兼容模型；保留HTTPS代理、超时、一次格式重试与失败提示。

## 配置真实模型

无 `AI_PROVIDER` 默认Mock。设置为 `openai-compatible` 后，缺少配置会报错，不回退Mock。参考 `.env.example`；真实密钥只放在被Git忽略的 `.env.local` 或部署平台安全环境变量中。

```text
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
```

另安全设置 `AI_API_KEY`。密钥不使用NEXT_PUBLIC前缀，不进入报告、聊天或日志。云环境代理密钥的允许目标域名必须为 `api.deepseek.com`；Vercel、腾讯云的配置各自独立，不能复制代理占位值。普通服务器只需有效原始密钥，应用自动读取 `.env.local`。

供应商/模型改变后重新启动。`GET /api/config`仅说明配置是否完整，不保证认证、额度或模型质量可用。每项真实请求都需用户明确勾选外发授权。接口只接受受支持HTTPS管理员地址，不允许用户指定任意目标URL。

## API

无状态演示接口：`POST /api/context`、`POST /api/analyze`、`POST /api/hints`、`POST /api/compare`。请求均使用JSON、task结构及真实模式的externalConsent；提示与比较还需要校验有效的报告。客户端身份、taskId不构成真实账号授权。本版本不提供云数据库CRUD或真实教师端权限。

- 流式限制请求体128KiB，跨站Origin拦截；反向代理必须保留正确Host与X-Forwarded-Proto。可用服务端 `APP_ORIGIN` 固定合法来源，例如正式HTTPS站点根地址。
- 输入不截断，错误保留文本；提供可读错误、requestId与状态码。
- 每次最多一次格式/证据修复重试，网络/权限/拒答/额度错误不自动重试。
- 每实例内存调用上限默认5次/分钟、50次/日，重试计数；重启清零，多实例不共享，不是金额预算。
- 幂等标识按请求体hash缓存同一操作10分钟，最多100条，范围为单进程匿名演示。真实试点需认证、共享持久化幂等与配额，不能靠当前机制提供全局费用保证。

## 评分与演示边界

内置规则为内部训练规则 `internal-v1`，不是任何省份年份的官方分项评分表。满分15/25仅是常见模板。没有教师确认的整体分档，因此完整辅助估分当前明确不可用，不编造一个高考分数。教师规则编辑与整体估分扩展属于后续能力。

Mock采用少量确定性检查：例如 `invite you attend` 结构、原文明示红围巾而续写出现蓝围巾的风险。其他检查明确标为可选/人工复核；模拟维度等级不是有效教育评价。真实Provider使用题型专用约束，不保证模型不会误判。

任务、全文、报告、提示、教师意见仅保存在当前浏览器。清除站点数据会丢失；共享设备上及时导出或删除。导出包含作文，需妥善保管。教师是同浏览器角色演示，不是受保护的真实账号；本版不应处理未经授权的真实学校数据。
