# 文思进阶

高中议论文论证能力训练 MVP。按《文思进阶 PRD v2.0》首轮 Sprint 0–1 实现，无模型密钥即可使用。

## 运行

Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

本地访问端口 3000。生产检查：`npm run lint && npm run typecheck && npm test && npm run build`；生产运行：`npm start`。

浏览器验收：`npm run test:e2e`。默认使用 `/usr/bin/chromium`，其他机器可通过 `CHROMIUM_PATH` 指定已安装的 Chromium 路径。

## 已实现

- 学习概览、题目/材料与正文校验、年级及任务要求、12000字符上限、短文提醒、匿名本地保存与删除。
- 六维模拟诊断，Zod 服务端输出校验与精确原文证据定位；论证结构与中立质疑。
- 分层提示、自主修改、互动轨迹；局部范例默认关闭。
- 二稿特征比较、两稿原文、维度变化及谨慎的进步报告；JSON 导出。
- 学生主动分享后教师可查看两稿、逐条采纳/修改/驳回，保存备注。

## 演示边界与数据

默认使用 MockAIProvider，以确定性词语匹配展示闭环，**不是智能模型诊断**，不产生模型费用。已实现 OpenAICompatibleProvider；仅在显式配置真实模式并取得用户同意后才发送题目、材料和作文到模型服务。

作文会发送到本机 Next.js `/api/analyze` 进行无状态模拟分析，任务和交互记录保存在当前浏览器 localStorage；清除站点数据会丢失记录。无需姓名、手机号或账号。JSON 导出包含作文与记录，请自行妥善保存。每篇作文列表提供删除入口。

教师是同浏览器的演示角色切换，**不是权限系统**，不用于真实学校数据或多人部署。API 仅校验无状态分析请求，不提供数据库读写和真实账号授权。上公网前需增加身份验证、服务端授权、限流和安全持久化。

二稿比较不会仅凭篇幅或措辞变化断言进步，也不能可靠自动认定已解决或新增问题；明确显示待人工复核。提示交互记录不能证明学生采纳，因此不推断修改来源。

## OpenAI 官方真实诊断配置

复制 `.env.example` 到被 Git 忽略的 `.env.local`，或在云环境设置中安全配置；禁止在聊天中提供密钥。

- `AI_PROVIDER=openai-compatible`：显式切换真实模式；缺少配置时会失败，不静默回退。
- `AI_BASE_URL=https://api.openai.com/v1`：HTTPS Chat Completions 兼容接口基地址。
- `AI_MODEL`：填写账户可用且支持 JSON object / Chat Completions 的模型标识。
- `AI_API_KEY`：只在服务端使用的安全密钥。不要使用 `NEXT_PUBLIC_` 前缀。
- 网络需要允许 `api.openai.com`。本云环境支持代理注入密钥，应用通过 undici EnvHttpProxyAgent 使用现有 HTTP(S)_PROXY / NO_PROXY 路由，保留 TLS 验证；无需读取原始凭据。

配置后重启服务，首页应显示“真实 AI 模式”；提交时勾选外部分析授权。`GET /api/config` 仅返回模式、模型名与配置完整状态，不证明密钥有效或模型可访问。真实请求结果应包含 `provider: openai-compatible` 和模型名。已验证本云环境的代理路由并触达模型接口；先前 OpenAI 服务返回额度不足；切换 DeepSeek 后，已通过应用 /api/analyze 完成一次真实 deepseek-chat 诊断，六个维度及全部引文均通过校验。这不等于教师教学效果验收。

默认单次超时25秒，JSON/结构/证据无效最多重试一次；网络、权限、拒答和额度错误不自动重试。不写入作文或供应商错误正文到普通日志。引文必须精确存在于原文，偏移索引由服务端按引文校正。事实、名言与数据仍需人工核实。

调用限制默认每分钟5次、每天50次（UTC日期）、每次最大4000输出token。重试也计入次数。这些限制是**单进程内存计数**，重启会清零，多实例不共享，并非持久化的金额预算。正式使用前必须在模型服务商账户设置预算/消费告警，并接入持久化配额与身份认证。最多12000字符的正文及两次受限输出控制单次请求规模，费用仍以供应商计价为准。


## DeepSeek 配置

使用相同的 OpenAICompatibleProvider：`AI_PROVIDER=openai-compatible`、`AI_BASE_URL=https://api.deepseek.com/v1`、`AI_MODEL=deepseek-chat`。安全配置 DeepSeek 创建的 `AI_API_KEY`，网络密钥允许的目标域名须为 `api.deepseek.com`；仅修改 BASE_URL 不会更新代理密钥目的地。保存后重启应用。模型接口使用按字段纠错的最多一次重试，并仅对0至5的整数维度标识作字符串归一化，不补造缺失诊断、分数或引文。API费用以服务商当前政策为准。
