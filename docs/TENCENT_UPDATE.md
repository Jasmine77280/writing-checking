# 腾讯云原地升级到 WriteWise

适用现有环境：Ubuntu 用户、Node.js v22.23.4、原 Git 仓库 `/home/ubuntu/apps/wensi`、systemd 服务 `wensi.service`、端口3001、已有 `.env.local` 的 DeepSeek 配置。脚本只升级该应用，不改变 Nginx、其他站点或防火墙。真实学校数据仍需后续认证、HTTPS及持久化权限。

发布前先确认服务器已续费并完成必要的实例/数据备份。脚本保留旧应用与环境文件，但不能替代腾讯云快照或整机备份。

脚本从仓库中检出新提交到独立发布目录，安装和构建，复制当前服务 `.env.local` 为600权限，不输出密钥；在本机临时端口验证启动、配置模式和主页。通过后使用专属 systemd drop-in 切换到新目录，仍监听3001；失败尝试恢复旧 drop-in 并重启旧服务，旧发布目录始终保留。

健康检查只证明服务启动和配置完整，不证明密钥额度、外部连接或批改质量。该流程不会自动发送付费模型请求。完成后用页面提交一篇虚构作文验证。

以ubuntu用户执行，不要使用sudo bash整个脚本。旧仓库有本地改动、服务用户/目录不符、配置缺失、模型不是deepseek-chat时会停止。不要为绕过检查删除文件，先反馈异常。

发布后的执行命令以聊天中给出的固定提交号为准，避免运行未经确认的新版本。脚本完成后会打印可直接执行的回滚命令。

升级完成后原仓库仍作为取代码的Git目录；正在运行的代码位于 `~/apps/writewise-releases/`。未来更新时重用该脚本，不能仅对旧仓库git pull就假定网站已经更新。

不要把.env.local、备份配置或服务器日志直接提交到Git或发到聊天。截图前遮挡可能存在的敏感信息。
